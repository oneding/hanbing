第五章　身、心、性：三层一起治

把前面两套东西合成一个能上手的操作顺序。

一、为什么需要分层

前面讲了九個西方流派、五套东方智慧。东西太多，用的时候会打架。所以需要一个简单的结构把它们装进去。

这个结构只有三层：身、心、性。

层它包括什么出了问题时的表现主要办法
身 呼吸、睡眠、运动、饮食、疼痛、紧张度、自主神经系统 心慌、胸闷、头晕、失眠、没劲、肠胃乱、肩颈硬、说不清的不舒服 先调身体：呼吸、动、睡、吃、感官落地
心 情绪、念头、信念、应对方式、行为模式 反复想、灾难化、自责、回避、反复检查、情绪一来就扛不住 命名、允许、看清歪曲、行为实验、暴露
性 价值观、意义感、对自己的根本判断、与他人的连接 空、迷茫、活不下去、觉得没有被爱过、做什么都没意思 立志、清点资源、修复连接、投入一件大于自己的事
关于「性」这个字

这里用的不是「性别」那个性，是「性命」「心性」那个性——你这个人最深处认为「我是谁、我要往哪儿去」的那个东西。古人讲「修身养性」，修的是行为，养的就是它。

二、最重要的：顺序不能反

三层不是并列的，是有先后顺序的。

  • 先治身。当身体已经警报大作的时候（心慌、失眠、吃不下、持续疼痛），「想通」「看开」这些上层办法全部失效。因为负责让你想通的那部分大脑，在这种状态下是降权的。这时候唯一有效的入口是往下走——把身体稳下来。
  • 再治心。身体稳了，你才有条件去辨认那些自动冒出来的念头、看见自己习惯性的应对方式、去做行为实验。
  • 最后才是性。「活着到底为了什么」这种问题，在还剩半口气、三天没睡的时候是不该问的，问了只会更绝望。它是要在前两层稳住之后，才有条件去碰的。
    • 所以这个网站所有条目的排序都遵循这个原则

    每一个症状的第一条建议，永远是身体动作；中间的七天练习处理念头和行为；最后的东方心法才是「怎么安住」。这不是套路，是因为人在不同的状态下，能接收到的东西不一样。

    三、三层自检：你现在卡在哪一层

    每个症状来的时候，先花一分钟做下面这张表。它能帮你决定「今天该从哪儿下手」。

    层打分（0–10，越高越严重）自检问题
    身 睡眠：____　体力：____　身体不适（心慌/疼/肠胃/头晕）：____ 最近三天睡够了吗？吃了吗？动了吗？
    心 念头停不下来：____　情绪强度：____　回避程度：____ 我有没有在躲某件事？有没有话说不出口？
    性 空与迷茫：____　觉得不被爱/没价值：____　孤独：____ 我多久没觉得快乐了？还有在乎的人或事吗？
    怎么用这张表

    哪层的总分最高，今天就从哪层入手——但永远保留「身」的底。

    特别提醒：如果「身」这一层的分数很高，尤其是睡眠和体力，先别急着做心性层面的练习。先把觉补上。很多「想不通」的事，睡够一周之后自然就通了。

    四、急则治标，缓则治本

    这是中医的一条原则，用在心理上特别合适。它区分两种不同的时刻：

    正在进行时（急）

    症状此刻正在发作：心跳快、手发麻、脑子里全是灾难、马上要崩溃。
    这时候的目标是「熬过去」，不是「解决」。办法只有身体层的：长呼气、脚踩地、冷水、走动、找个人说话、换个地方。
    任何「想开点」「分析分析」在这个时候都是添乱。

    间歇期（缓）

    现在没事，但症状反复来。
    这时候才是做「本」的工作的时候：看清它的维持机制、调整你的应对方式、做暴露练习、处理那些一直没说出口的话、修复关系。
    这时候做「心」和「性」层面的事才有效。

    很多人搞反了。发作的时候试图分析自己的童年、试图想通人生意义——结果越想越崩；没事的时候又什么都不做，干等着下次发作。正确的做法是反过来。

    五、一个贯穿全站的四步操作

    不管是哪一种困扰，这个网站给的流程都是下面这四步。建议你把它抄下来贴在床头。

  • 落地（身）。双脚踩实、长呼气（呼气比吸气长）、喝口水、站起来。让身体先知道你还站得住。约两分钟。
  • 命名（心）。给这个状态起个名字，越具体越好：不是「我很难受」，是「我现在胸口发紧、心跳一百、脑子里全是明天开会要被骂」。说不出来就写下来。这一步能让你从「我被淹了」变成「我在看着它」。
  • 允许（心）。说一句固定台词：「好，你来了。我给你留个位子。」不压制、不分析、不评判。这一步是整个流程里最难、也最省力的一个。
  • 回到手上的事（身 + 性）。去做一件此刻能做的最小的事——洗碗、走十分钟、回一条消息、把这一页看完。做完之后记一笔：「今天我做了。」

    • 这四步看起来简单，但它包含了：身体调节、认知解离、接纳、行为激活、自我效能感——五个不同流派的东西，压缩成了两个动作。

    知止而后有定，定而后能静，静而后能安，安而后能虑，虑而后能得。

    《大学》

    知道停在哪里（止），才能定得下来；定下来才能静；静了才能安；安了才能好好思考；能思考，才能有所得。《大学》给出的，是一个完整的操作顺序。

    四书里的这一句，就是上面那四步的古典版本：「止」= 停下来、落地；「定」= 身体稳住；「静、安」= 允许之后的那个状态；「虑」= 这时候才有条件去想；「得」= 才有结果。
    重点是第一步：止。现代人最缺的就是这个「停」的能力——不停下来，后面全免谈。

    到这里，「前半部分的底子」就打完了。接下来是本体的六十一場景。你可以按自己的情况直接翻到对应的那一节，每条的结构都一模一样：一句话说清 → 自查 → 为什么会这样 → 现在就能做的五步 → 七天天练习 → 真实案例 → 东方心法 → 别被这些说法骗了 → 红灯 → 一句话记住。
